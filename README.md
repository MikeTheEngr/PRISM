## Why PRISM?

Following crypto and stocks usually means switching between several apps, and most AI "signal" tools show you a verdict with no reasoning and no way to judge it.

PRISM puts crypto and stock prices on one dashboard and attaches a direction, a confidence score and a plain-language explanation to every signal. It never promises an outcome: signals are pattern-based, generated by AI, and labelled as such.

## What PRISM Can Do

### Market Data

- **Unified prices** — 20 crypto assets (CoinGecko) and 8 stocks (Alpha Vantage) in one list
- **Last-known-price fallback** — if a provider fails or hits its quota, the last good price is served and marked as delayed instead of disappearing
- **Parallel fetching** — prices for all assets are retrieved concurrently

### Intelligence

- **AI signals** — direction (bullish, bearish or neutral), a 0 to 100 confidence score, and a short reasoning grounded in the asset's real numbers
- **Dual provider** — Groq first, automatic fallback to Gemini
- **Strict validation** — every AI response is checked against a schema before it is shown; invalid output is discarded, never repaired or invented
- **Built-in disclaimer** — every signal object carries its disclaimer in the data model
- **Cached** — signals are generated once per asset and reused for 30 minutes

### Accounts

- **Sign up, log in, token refresh** — Supabase Auth, with refresh handled quietly by the frontend
- **Watchlist** — add and remove assets, with a per-account limit
- **Tiered access** — anonymous visitors see the top 3 signals, logged-in users the top 5
- **Early-access flag** — people from the original waitlist are marked as founding members when they log in with a confirmed email

### Reliability

- **Two-layer cache** — in-memory plus Upstash Redis, with a cooldown so a slow Redis never slows every request
- **Safe logging** — errors are logged by type and status only, so API keys never reach the logs
- **Configurable models** — AI model names come from environment variables, so a retired model is a one-line fix

## Roadmap

- [x] Phase 1 — Market data layer (crypto + stocks) with caching and fallbacks
- [x] Phase 2 — AI signal engine with validation and provider fallback
- [x] Phase 3 — Accounts, watchlist, token refresh, deployment
- [ ] Phase 4 — Store every signal and score it against later prices (public track record)
- [ ] Phase 5 — Real indicators (RSI, moving averages, volatility) computed server-side, with AI explaining them
